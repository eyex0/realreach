# Task Status — the 22 build tasks vs what exists today

> Written 2026-09-29 so the prompts in [`OPENCODE_TASKS.md`](./OPENCODE_TASKS.md)
> are not executed against work that is already done.

**Summary:** roughly a third of the platform core already exists — the data
model, the deterministic scoring, the evidence-only outreach rules, the
approval gate, monitoring, and the first-run path. What does **not** exist is
the Next.js scaffold, Prisma, an LLM, a queue, billing, and email delivery.

Legend: `[x]` done and verified · `[~]` partially done, or done differently ·
`[ ]` not started.

## What the pilot has that this list does not mention

The field-ops half of the product is complete and verified on a real phone:
campaign lifecycle, PostGIS task splitting, GPS sessions, photo/quantity/note
evidence, offline outbox with replay, machine verification with confidence and
freshness scores, human proof review, and the €0.04/piece payout ledger
(generate → approve → pay, immutable once paid). See [`../PLAN.md`](../PLAN.md).

## Recommended order from here

1. **Task 11 — AI foundation.** Everything in Priorities 1 and 4 that is still
   `[~]` is waiting on it. Nothing else unlocks as much.
2. **Task 6/7 — connectors and ingestion.** Priorities 2 and 9 both depend on
   data that does not exist yet: without a connector, "discover companies" can
   only ever return the seed.
3. **Task 3 (workspaces) and Task 4 (layout).** Small, and the current platform
   UI is a single page, so navigation is a real gap.
4. **Task 5's missing half** — a real company search page with pagination.
5. **Task 18 — credits.** Only after a metered action exists to charge for.

Tasks 12, 13 and 15 become mostly prompt work once 11 exists, because the
contracts, guardrails and evidence requirements are already implemented and
tested against the deterministic versions.
